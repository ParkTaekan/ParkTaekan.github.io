⬇ 앱 받기 (APK, 약 81MB)

와이파이에서 받는 것을 권합니다 · 2026년 10월 25일 빌드 · 판 1.0.1

설치 방법

  1. 위 앱 받기를 누릅니다. "이 파일은 기기에 해로울 수 있습니다"가 나오면 다운로드를 누릅니다.
  2. 다 받으면 화면 위 알림(또는 브라우저 아래)의 AIAvatarPet.apk를 눌러 엽니다.
  3. "이 출처의 앱을 설치할 수 없습니다"가 나오면 설정 → 이 출처 허용을 켜고 뒤로 돌아옵니다.
  4. 설치를 누릅니다. "Play 프로텍트" 안내가 나오면 세부정보 → 무시하고 설치를 누릅니다.
  5. 설치가 끝나면 열기. 앱 이름은 ai_avatar_pet으로 보입니다.
카카오톡 안에서 링크를 열면 받기가 잘 안 될 수 있습니다. 링크를 길게 눌러 다른 브라우저로 열기(삼성 인터넷·크롬)를 고르세요.
예전에 받은 테스트판이 있으면 그대로 덮어 설치됩니다. "패키지가 기존 패키지와 충돌" 오류가 나면 예전 앱을 지우고 다시 설치하세요.

알아 둘 것

  • 시험판이라 바뀌는 대로 새로 올립니다. 새 판이 나오면 이 페이지에서 다시 받아 덮어 설치하세요.
  • 대화 기능은 각자의 Gemini API 키를 넣어 씁니다 (키 없이도 펫은 움직이고 기본 말은 합니다).
  • 이상한 점은 만든 사람에게 카톡으로 알려 주세요.
